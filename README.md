# Country-Data-Comparison

## Project Overview
This project explores economic and social indicators across countries using Power BI and Power Query.

## Objectives
- Compare GDP per capita across countries.
- Explore the relationships between GDP per capita and life expectancy.
- Explore the relationships between GDP per capita and infant mortality.
- Examine internet usage across countries.

## Tools Used
- **Power BI:** Data visualization and dashboard development.
- **Power Query:** Data cleaning and transformation.

## Dataset
The dataset contains country-level economic and social indicators. Selected columns were used for the analysis.

## Data Preparation
- Selected relevant columns.
- Removed rows with more than 85% missing values.
- Excluded non-country entries and country groupings.
- Prepared data for analysis and visualization.

## Dashboard
The interactive dashboard presents country comparisons and explores relationships between economic and social indicators.

## Project Status
Dashboard development and documentation are in progress.
